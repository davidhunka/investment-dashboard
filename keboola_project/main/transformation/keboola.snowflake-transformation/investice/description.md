This transformation processes investment and transaction data from various sources to generate two main outputs: a detailed investment portfolio report and a consolidated transaction dataset. The investment data is formatted and analyzed to calculate monthly and yearly growth, initial values, and historical comparisons, culminating in a comprehensive portfolio report. The transaction data from main accounts and credit cards is cleaned and unified into a single dataset, providing a complete view of financial activities.

The transformation involves creating intermediate tables to facilitate calculations and data integration. For investments, it calculates growth metrics over different periods and combines them into a report that includes profit ratios. For transactions, it removes entries with missing dates and merges data from multiple account types into a unified format. The final outputs are stored in specified destinations for further analysis or reporting.
