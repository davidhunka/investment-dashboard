# Uživatelská pravidla pro příkazy

- **Vysvětlení a bezpečnost příkazů**: U každého terminálového příkazu, který předkládáš uživateli ke schválení, musíte vždy:
  1. Stručně a jasně vysvětlit, co tento příkaz dělá a jaký je jeho účel.
  2. Výslovně zhodnotit jeho bezpečnost (zda je bezpečný, nebo zda představuje jakékoliv riziko jako modifikace/mazání souborů, přepisování dat či síťové operace).
